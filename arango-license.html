ArangoDB Licensing & Dashboards 📜

Understanding Community vs. Enterprise costs and the built-in Web UI.

Licensing Costs: $0.00

For building the JEV Second Brain, your ArangoDB software licensing cost is exactly $0.00. ArangoDB operates on an open-core model with two distinct editions:

Community Edition (Free)

Released under the open-source Apache 2.0 License. It is completely free for both commercial and personal use. Most importantly, it includes everything required for the JEV architecture:

  • Native Graph Traversals
  • ArangoSearch (Vector Embeddings & Cosine Similarity)
  • AQL (ArangoDB Query Language)
  • Built-in Web Dashboard

Enterprise Edition (Paid)

Designed for massive corporations. It requires a paid license and adds features that a personal Second Brain (even one with 100k files) simply does not need:

  • SmartGraphs: For sharding graphs across multiple servers (unnecessary for <100M nodes).
  • Datacenter-to-datacenter replication.
  • Advanced auditing and LDAP integration.

The Built-In Web Dashboard

Unlike PostgreSQL or Qdrant which require you to install clunky third-party tools (like DBeaver or pgAdmin) to see your data, ArangoDB ships with a beautiful, fully-featured Web UI right inside the binary.

What you can do in the ArangoDB UI:

  • 🕸️
    Visual Graph Explorer Click on a project node and visually watch the UI expand the graph outward to show connected team members, tasks, and semantic vectors.
  • 💻
    AQL Query Editor Write and execute queries with syntax highlighting. It includes an "Explain" feature that visually shows you the execution plan and query latency.
  • 📊
    Server Metrics Monitor your RAM usage, disk I/O, and HTTP connections in real-time—crucial for managing costs on Fly.io.

How to Access the UI Securely on Fly.io

Because we enforce the strict security rule of placing ArangoDB on Fly.io's private `.flycast` network, the dashboard is safely hidden from the public internet.

To view your Second Brain dashboard from your local Mac, you create a secure WireGuard tunnel using the Fly CLI:

# 1. Open a secure tunnel to the internal ArangoDB port
flyctl proxy 8529:8529 -a my-arangodb-app

# 2. Open your browser to the local tunnel
open -a "Google Chrome" "http://localhost:8529"

# 3. Log in with your 'root' user and the password stored in Azure Key Vault.
