Cost Analysis 💰

What does it cost to process 100,000 files?

The 100k File Ingestion Problem

When processing a Second Brain of this magnitude, the true cost lies not in querying, but in Ingestion (Extracting entities for Neo4j and summaries for Qdrant).

Cloud API (OpenAI / OpenRouter)

  • Token Math: ~1,000 tokens per document * 100,000 files = 100 Million Tokens.
  • GPT-4o-Mini: ~$0.15 per 1M input tokens → $15.00 for one pass.
  • GPT-4o / Claude 3.5 Sonnet: ~$3.00 to $5.00 per 1M input tokens → $300 to $500 for one ingestion pass.
  • Embeddings: ~$2.00 to embed 100M tokens.

Total Ingestion Cost: $17 - $500+

Local Execution (Ollama)

  • Token Math: 100 Million Tokens run on your local hardware.
  • Inference Cost: $0.00 (Requires an M1/M2/M3 Mac or discrete GPU).
  • Embeddings: $0.00 (Using `nomic-embed-text`).
  • Time Cost: Generating 100M tokens locally might take several days of background processing.

Total Ingestion Cost: $0.00 (plus electricity)

Execution Costs by Use Case
