JEV macOS Native Install 🍎

Harnessing Apple Silicon (M1/M2/M3) for your Second Brain

Why macOS? (Metal Acceleration)

Apple Silicon's Unified Memory Architecture (UMA) is a game-changer for local LLMs. Unlike PCs that require separate VRAM on a dedicated GPU, a Mac with 64GB of Unified Memory can load massive 70B parameter models natively.

1. Install Ollama via Homebrew

Open your macOS Terminal and run:

brew install ollama
brew services start ollama

This installs Ollama and ensures it runs as a background daemon whenever your Mac starts.

2. Pull the JEV Stack Models

JEV requires two distinct models: one for dense entity extraction, and one for hyper-fast vector embeddings.

# For Neo4j Graph Extraction (The Brain)
ollama pull llama3

# For Qdrant Vectors (The Indexer)
ollama pull nomic-embed-text

3. Install the JEV Python Engine

Ensure you have Python 3.10+ installed. Then install the LangChain wrappers.

pip install langchain-community qdrant-client neo4j

4. Running JEV on your Mac (The Execution Loop)

Once Ollama is running in the background on your Mac, you can execute JEV's Python pipeline entirely locally. Here is a detailed example of how JEV processes a local Markdown file from your macOS ~/Documents/ folder.

import os
from langchain_community.llms import Ollama
from langchain_community.embeddings import OllamaEmbeddings
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 1. Connect to macOS Local Ollama Daemon
# This runs entirely on your Apple Silicon chip (Zero Cloud Cost)
mac_llm = Ollama(model="llama3", base_url="http://localhost:11434")
mac_embedder = OllamaEmbeddings(model="nomic-embed-text")

# 2. Read a Local Markdown File from the macOS Filesystem
file_path = os.path.expanduser("~/Documents/SecondBrain/project-phoenix.md")
with open(file_path, "r") as file:
    raw_document = file.read()

# 3. JEV Action A: Extract Graph Relationships via Llama 3
print("Extracting Graph Nodes using Apple Silicon...")
cypher_extraction_prompt = f"Extract Neo4j relationships from this text:\n{raw_document}"
graph_nodes = mac_llm.invoke(cypher_extraction_prompt)
# -> Send graph_nodes to local Neo4j database

# 4. JEV Action B: Chunk and Vectorize
print("Vectorizing text via Nomic-Embed...")
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_text(raw_document)

# 5. Embed the chunks into your local Qdrant Vector DB
vector_embeddings = mac_embedder.embed_documents(chunks)
# -> Send vector_embeddings to local Qdrant

print("✅ JEV Local Ingestion Complete!")

The macOS Advantage: Because Apple Silicon uses Unified Memory, the pipeline can seamlessly switch between the heavy llama3 extraction and the lightweight nomic-embed-text vectorization instantly, without transferring data across a slow PCIe bus like traditional PC graphics cards.
