Installing & Processing Locally 💻

Zero-cost ingestion for your 100k files

Step 1: Install Ollama

Ollama allows you to run massive LLMs as background processes natively on macOS, Linux, and Windows.

# For macOS/Linux (via Homebrew/Curl)
curl -fsSL https://ollama.com/install.sh | sh

# Start the daemon
ollama serve

Step 2: Pull the Models

You need two models: One for generating embeddings (Qdrant), and one for entity extraction (Neo4j).

# Pull the extraction model (Llama-3 8B is excellent for extraction)
ollama pull llama3

# Pull the embedding model (Nomic Embed Text)
ollama pull nomic-embed-text

Step 3: Setup the LangChain Processing Script

Write a python script that connects LangChain to your local Ollama port `localhost:11434`.

import os
from langchain_community.llms import Ollama
from langchain_community.embeddings import OllamaEmbeddings

# 1. Initialize Local LLM
llm = Ollama(model="llama3", base_url="http://localhost:11434")

# 2. Initialize Local Embeddings
embeddings = OllamaEmbeddings(model="nomic-embed-text", base_url="http://localhost:11434")

def process_file(file_content):
    # This runs 100% locally on your machine
    vector = embeddings.embed_query(file_content)
