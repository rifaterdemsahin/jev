Local Performance Benchmarks ⚡

Throughput, VRAM, and Token/Sec Analysis on Apple Silicon

Throughput: Ingesting 100k Files

The most expensive operation in JEV is the initial ingestion loop—taking raw Drive files, extracting graph relationships via `llama3`, and vectorizing chunks via `nomic-embed-text`.

Apple Silicon Model Unified Memory Tokens / Sec (Llama 3 8B) Est. 100k File Ingestion Time
M1 Base 8GB / 16GB ~25 t/s ~72 Hours
M2 Pro / Max 32GB+ ~55 t/s ~36 Hours
M3 Max 64GB - 128GB ~90+ t/s ~18 Hours

* Note: Time estimates assume an average of 1,000 tokens per file.

The Context Optimization Loop

When querying the Hermes Bot, performance drops drastically if you load too much context. Apple Silicon excels at generation, but large prompt processing (Prompt Eval) is bottlenecked by memory bandwidth.

Unoptimized Query

  • Injects 20 whole files (20k tokens).
  • Prompt Evaluation Time: 12-15 seconds.
  • High chance of LLM "lost in the middle" hallucination.

JEV Optimized Query

  • JEV filters via Qdrant/Neo4j first.
  • Injects only the top 5 paragraphs (800 tokens).
  • Prompt Evaluation Time: < 0.5 seconds.
  • Time-to-first-token is virtually instantaneous.
